# AtomGit CLI v0.15.0

v0.15.0 是安装与更新层的大规模加固版本：由四轮全面评审（第二、四、五、六轮）与第七轮发布就绪评审驱动，共 77 个提交，涵盖安装事务与目标识别、四把锁的并发与陈旧回收语义、更新状态按坐标/渠道分域、跨渠道入口保护、doctor 诊断完整性；同时 release 命令行为全面对齐 gh 语义，仓库 URL 收敛至 `atomgit-cli/cli`。命令入口保持 `gc` / `gitcode` 不变。

## ⚠ 行为变更（升级前必读）

以下 9 项行为与本版本之前的发布语义不同，脚本与自动化消费方请先评估：

1. **`release download` 目标已存在默认拒绝**（原静默覆盖）；新增 `--clobber`（强制覆盖）与 `--skip-existing`（跳过已存在），两者互斥（gh 对齐）
2. **`release download` 点名资产任一未命中 → exit 1** 并附可用资产名单（原 exit 0 假成功）
3. **`release upload` 同名/批内重名整批拒绝**（原平台未定义行为）；失败时附已上传清单便于重试
4. **`release list` 真分页**：`--limit` 大于 100 时跨 API 页生效；新增 `--page` 参数
5. **安装器拒绝接管 pnpm / pip 等外来渠道入口**（原静默销毁——保护性收紧，需先卸载原渠道或显式 `--target-dir`）
6. **补全落点遵循 `XDG_DATA_HOME` / `XDG_CONFIG_HOME` / `BASH_COMPLETION_USER_DIR`**：设置了这些变量的用户，shell 补全文件位置随之变化
7. **`gc version` 文本与 `--json` 的 url 统一为 `atomgit-cli/cli`**：解析该字段的机器消费方需适配
8. **doctor Windows 候选按 `PATHEXT` 环境序**（`.COM` 优先于 `.EXE` 等）
9. **`release list` / issue 列表中文截断修复**（rune-safe，宽字符不再被截半）

## 推荐升级方式

### 短命令快速升级

可信的个人本地环境可优先使用短命令（推荐坐标）：

```bash
npx -y atomgit-cli@latest install
gitcode version
gitcode doctor install
```

等价坐标：`npx -y @gitcode-cli/cli@latest install`（旧坐标长期可用，无需迁移）。

短命令会继承当前目录和用户的 npm 配置。请仅在确认这些配置（包括 `.npmrc`）可信时使用。

CI、审计、未知项目目录或自定义 npm registry 环境，使用安全强化命令：

```bash
npx --yes --ignore-scripts --registry=https://registry.npmjs.org atomgit-cli@latest install
gitcode version
```

（scoped 坐标加固形式：`npx --yes --ignore-scripts --registry=https://registry.npmjs.org --@gitcode-cli:registry=https://registry.npmjs.org @gitcode-cli/cli@latest install`）

### 锁定版本安装

```bash
npx --yes --ignore-scripts --registry=https://registry.npmjs.org atomgit-cli@0.15.0 install
gitcode version
```

（scoped 坐标锁定形式：`npx --yes --ignore-scripts --registry=https://registry.npmjs.org --@gitcode-cli:registry=https://registry.npmjs.org @gitcode-cli/cli@0.15.0 install`）

### 其他渠道

- **npm 全局（经典）/ npm-bootstrap**：`gc update`，或上面的 npx 命令
- **pnpm 全局**：`pnpm add -g atomgit-cli@latest`（`gc update` 会给出该指引）
- **Homebrew**：`brew update && brew upgrade gc`
- **pip / pipx**：`pip install -U gitcode-cli` / 在对应环境升级
- **deb / rpm**：通过系统包管理器升级
